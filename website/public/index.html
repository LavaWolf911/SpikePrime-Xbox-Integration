Getting Started

To use Pybricks with your LEGO Spike Prime:

  1. Go to code.pybricks.com
  2. Follow the firmware flashing instructions
  3. Connect your hub via USB and start programming!

Examples

// Drive forward
from pybricks.hubs import PrimeHub
from pybricks.pupdevices import Motor
from pybricks.parameters import Port
from pybricks.tools import wait

hub = PrimeHub()
motor = Motor(Port.A)

motor.run_time(500, 1000)
